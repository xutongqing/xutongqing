# 同庆 · xutongqing

**C# / .NET 开发者 · WPF 桌面应用 · 实用开发工具**

在上海的软件开发者，主要使用 C# 与 .NET 构建桌面应用和后端服务，也通过小型项目探索设备通信、自动化与交互式原型。

*Building desktop applications and practical tools with C# and .NET.*

## 技术方向

- **桌面应用**：C#、.NET、WPF。
- **后端服务**：ASP.NET Core 与接口开发。
- **工具与原型**：iOS 设备通信、SwiftUI 示例，以及 JavaScript 交互演示。

| 项目 | 内容 | 定位 |
